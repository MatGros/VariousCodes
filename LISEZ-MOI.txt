================================================================================
FONCTIONNALITÉS
================================================================================

✓ 3 Modes de calcul :
  1. Calcul de section recommandée
  2. Distance maximale admissible
  3. Courant maximal admissible

✓ Conforme aux normes NF C 15-100 & IEC 60364

✓ Base de données intégrée :
  - Câbles U-1000 R2V (sections 1.5 à 240 mm²)
  - Câbles HO7RNF (sections 1.5 à 16 mm²)

✓ Prise en compte :
  - Coefficients de correction (température, groupement, mode de pose)
  - Monophasé et triphasé
  - Mode moteur (chute de tension 5%)
  - Facteur de puissance réglable

✓ Visualisations graphiques interactives (Chart.js)

✓ Export des résultats :
  - Format CSV (pour Excel)
  - Format PDF (note de calcul complète)

✓ Sauvegarde automatique des paramètres (localStorage)

✓ Mode Expert : détails des calculs
